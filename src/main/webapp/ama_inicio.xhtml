Bienvenido a AMA

El Asistente de Medición de Aprendizaje a través de gamificación retro. Rigor analítico en un entorno interactivo de 16 bits.

Módulo 01 // Cognitivo visibility

Test Visual: El Intruso del Bosque

Evaluación de discriminación visual y atención selectiva mediante la identificación de patrones anómalos en entornos naturales pixelados.

Módulo 02 // Lenguaje menu_book

Test Verbal: El Pergamino de las Órdenes

Medición de comprensión auditiva y seguimiento de instrucciones complejas a través de un sistema de narrativa lúdica guiada por audio.

Módulo 03 // Ejecución target

Test de Concentración: La Escolta Pixelada

Evaluación de la atención sostenida, velocidad de reacción y control inhibitorio en entornos de alta velocidad con distractores dinámicos.

¿Listo para administrar las pruebas?

Plataforma desarrollada para el registro y monitoreo clínico de estudiantes. Acceda al panel de administración para visualizar métricas, tiempos de respuesta y resultados en tiempo real.
